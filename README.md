# Startupmap Copilot prototype

Clickable prototype of one Copilot flow: **All chats**, opened from "View all" in the sidebar.

- Look: Serenity 1.0, exactly as in Figma (Startupmap Dashboard, section "Alan's request", frames 01, 31, 32, 33, 34). Icons are exported from Figma as SVG at their original size and colour. Light mode only.
- Motion: Serenity 2.0 tokens and patterns (Enter/Dialog, Exit/Dialog, Enter/Scrim, Exit/Scrim, Enter/Item, Exit/Item, Enter/Fade, Enter/Toast, Exit/Toast, Feedback/Hover, Feedback/Press), reduced motion included.

## Run

Open `index.html` in a browser. No build step. `#all-chats` opens the dialog directly.
