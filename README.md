# Startupmap Copilot prototype

Clickable prototype of one Copilot flow: **All chats** (browse, search, preview, rename, delete with undo).

- Look: Serenity 1.0 components as they are in Figma (Startupmap Dashboard, section "Alan's request", frames 01, 31, 32, 33).
- Motion: Serenity 2.0 tokens and pattern classes (Enter/Dialog, Exit/Dialog, Enter/Scrim, Enter/Item, Exit/Item, Enter/Fade, Enter/Toast, Feedback/Hover, Feedback/Press), reduced motion included.

## Run

Open `index.html` in a browser. No build step.

- `#all-chats` opens the dialog, `#rename` opens it in rename state.
- Shortcuts: Cmd/Ctrl+K opens All chats, arrows move, Enter opens, Esc closes.
- Dark mode follows the system setting.
